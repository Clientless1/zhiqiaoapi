# 网站与 API 分开接入

更新：2026-11-14（北京时间）。

网站、登录、支付继续使用 `https://zhiqiaoapi.fun` 和现有 Cloudflare Tunnel。客户端模型请求可使用已部署的 `https://111.228.31.204` 直连入口。

## 配置

在「管理后台 → 站点设置 → API 接入地址」填写 HTTPS 源站地址，不含 `/v1`：

```text
https://111.228.31.204
```

设置保存在 PostgreSQL 的 `site_brand.api_origin`，即时生效。网站的 `PUBLIC_BASE_URL` 保持原域名。密钥页、CC Switch 导入、手动配置、首页示例、工作台接入地址、API 文档、调试台复制的 cURL，以及 Linux/macOS/Windows 安装脚本统一读取该设置。后台会拒绝 HTTP、账号密码、路径、查询参数和片段，避免把错误地址写进客户端配置。

客户端使用的路径：

| 客户端 | 接入地址 |
| --- | --- |
| OpenAI SDK / Codex / OpenCode | `https://111.228.31.204/v1` |
| CC Switch 中的 Claude Code | `https://111.228.31.204` |
| Anthropic SDK | `https://111.228.31.204/anthropic` |

已有客户端配置不会被远程重写，需要重新导入 CC Switch 或修改 Base URL。密钥保持原值。旧域名 API 仍然可用，不对 POST 请求进行重定向或自动重放。

网站登录会话、后台请求、支付和 OAuth 回调继续使用网站地址。网页调试台的实际请求保持同源，复制出去的示例使用 API 接入地址。

## 延迟边界

本次优化移除客户端 API 的 Cloudflare 跨境隧道链路，不会缩短模型推理本身的耗时。排查时分别测量同一动态小接口的首字节时间，以及模型请求的首个有效事件时间；不要把 CDN 命中的静态文件当作模型调用延迟。

2026-11-14 检查时，隧道四条连接均落在 Los Angeles，QUIC RTT 为 168～187 毫秒。源站动态小接口约 2 毫秒。同一客户端交替请求 `/api/public/navigation` 各 6 次，域名首字节中位数为 1.303 秒，HTTPS IP 为 0.083 秒，全部返回 200。结果依赖客户端线路，不代表所有用户或完整模型生成时间。

## HTTPS 与维护

公网 IP 使用受信任的 Let's Encrypt IP 证书，不需要关闭 TLS 校验。续期由已有 `zhiqiao-ip-cert-renew.timer` 负责；检查续期服务和证书有效期后再启用此入口。两层 Nginx 继续禁用模型请求缓冲和缓存，保留原有 API 鉴权、限额及计费。

恢复域名作为客户端默认入口：清空后台「API 接入地址」并保存，再让用户更新客户端配置。修改该设置无需重启或操作数据库卷。已打开的页面需刷新以取得新设置。
