# zhiqiaoapi Documentation

zhiqiaoapi is a self-hosted Rust LLM API gateway for OpenAI-compatible and Anthropic-compatible APIs, model routing, multi-tenant API keys, usage tracking, cost management, billing, and enterprise private deployment.
