# 图像与视频规格定价

在「管理后台 → 上游服务 → 模型价格」设置。价格使用站点当前币种，支持 6 位小数。

## 图像

选择按张计费后，可保留统一单价，也可「添加规格价格」，分别填写尺寸、画质和每张价格。例如：

| 尺寸 | 画质 | 单价 / 张 |
| --- | --- | --- |
| 1k | * | 0.05 |
| 2k | * | 0.08 |
| 2k | high | 0.12 |
| * | * | 0.06 |

请求参数 `size`（也接受 `resolution`）和 `quality` 决定使用哪个价格。`auto` 对应未传该参数，`*` 是兜底规则。精确尺寸优先，其次匹配长边为 1024/2048/4096 的 1K/2K/4K 档，最后使用兜底规则。同一尺寸下，具体画质优先于 `*`。

没有匹配的规则时，请求会在预扣余额和调用上游之前被拒绝。添加兜底档位可覆盖未单独定价的规格；不希望开放其他规格时，不设置兜底即可。删除全部规格价格后恢复统一单价。

支持 JSON 图像生成、multipart 图像编辑/变体，以及 Responses 转图像的异步任务。异步任务保存创建时的报价，后续改价不会改变已创建任务的结算单价。

## 视频

可以新增、修改和删除分辨率档位，多个分辨率用逗号分隔，`*` 表示兜底。具体分辨率优先于兜底。

- 按秒计费：填写每秒价格，按生成时长结算。
- 按百万 tokens 计费：填写 token 价格和每秒预估 tokens，预估值用于预扣；结算按上游返回的实际用量。
- 勾选「统一单价」时，有无视频输入使用同一价格；取消后可分别定价。

未传视频规格时沿用原有默认值：480p、5 秒；模型名带分辨率后缀时优先推断该分辨率。

## 模型广场

卡片显示前 4 档价格，点击「查看全部」或详情可查看完整价格表。仅规格、画质、输入条件和计费单位相同的报价合并为价格区间。登录后的价格包含用户组倍率。图像/视频有规格价格时不使用统一单价做费用估算。

## 发布与回退

迁移 0023 只新增 JSONB 字段，不更改已有价格。旧管理客户端省略该字段时保留已配置的图像档位；显式传空数组才清空。

旧二进制的 SQLx 不认识新迁移记录。紧急回退需先停新后端，仅移除 `_sqlx_migrations` 中版本 23 的记录，再启用旧镜像；保留 `image_price_tiers` 列及所有业务数据。迁移可重入，重新发布时能够保留并重新使用这些价格档位。不要为回退恢复整库覆盖上线后的用户交易。
