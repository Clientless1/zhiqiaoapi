# 模型广场与上游供应链

项目沿用 AGPL-3.0-only 开源许可。本文说明模型发布、采购报价与价格展示的边界。

## 页面入口

| 入口 | 用途 |
| --- | --- |
| `/models` | 公开模型目录，展示基础售价 |
| `/home/models` | 用户侧模型广场，应用当前用户组价格倍率 |
| `/admin/models` | 管理员查看对外发布的模型目录 |
| `/admin/supply-chain` | 管理员采购报价、供应商、渠道比较与预算场景 |
| `/admin/channels` | 上游协议、地址、密钥、模型发现、售价、优先级、权重和诊断 |

模型广场支持文本、图片、视频、音频筛选，供应商筛选、搜索和价格排序。详情展示完整的渠道价格方案、缓存价格、视频档位、请求示例与基础费用预估。首页搜索和供应商链接可通过 `q`、`provider`、`type`、`sort=price` 查询参数进入广场。

## 上游接入步骤

1. 在渠道管理选择供应商，配置上游协议、地址与合法持有的密钥或凭证。
2. 发现并启用模型，核对端点的模型范围，运行对应能力的诊断。
3. 按模型类型配置对外售价。文本按百万输入 / 输出 tokens，图片按张，音频按秒；视频配置分辨率、是否含视频输入，以及按秒或官方 token 档位。
4. 在模型供应链中记录每条渠道、每个模型的供应商、采购成本、月度预算与采购备注。金额统一使用站点结算币种；外币采购价需先换算。
5. 在场景比较中选择同一模型、填写假设月用量，对照渠道成本与基础售价，辅助决定渠道优先级和权重。最终路由仍由现有路由策略决定，不会自动切换为最低报价渠道。

文本通过适配的 OpenAI / Anthropic 接口接入；图片使用兼容图片生成 / 编辑的上游；视频使用兼容异步任务的上游，须同时验证创建、查询与内容获取。端点协议兼容不代表支持所有模型能力，应以渠道诊断和实际接口能力为准。

## 对外发布与价格规则

目录来自真实的渠道售价，不包含预置演示报价。发布要求供应商、渠道、模型和有效售价均已启用，模型可用，至少有健康且范围匹配的端点，以及可用密钥或启用的供应商凭证。目录是状态快照，不能保证每次调用成功。

同一个供应商、模型和计量类型可能有多个渠道价格。卡片显示价格范围；详情按完整方案计算，避免将不同渠道的最低输入价、最低输出价组合成实际不存在的报价。最终价格由实际路由及用户组策略决定。

目录展示全站已发布模型。项目模型白名单、模型别名、智能路由与 API Key 权限继续由现有项目配置控制；广场不是某个 Key 的权限清单。嵌入、审核等文本计量模型应使用对应接口；详情中的对话示例仅适用于支持对话的模型。

## 采购成本与预算

采购报价独立存储在 `channel_procurement`，不会改变用户扣费、余额、对外售价或现有计费记录。采购数据仅管理员可读写，公开目录不返回渠道 ID、渠道名称、上游地址、密钥或采购报价。

- 空白采购金额为未知；`0` 为免费，不能混同。
- 文本记录输入、输出、缓存读取 / 写入的每百万 token 成本；图片 / 音频分别记录每张 / 秒成本。
- 视频可记录统一单位采购报价；按秒计费填写每秒成本，官方 token 计费填写每百万 token 成本。当前不支持供应商视频分档成本比较。
- 场景比较使用当前报价与假设用量，不是历史实际采购账单；文本场景不含缓存及其他额外费用。毛利率按基础售价计算，不包含用户组折扣、税费、汇率波动等。
- 月度预算是场景提醒阈值，超出时显示提示；不会自动停用渠道或执行实时采购限额。

## API 与升级

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/public/models` | 公开基础售价 |
| GET | `/api/user/models` | 用户会话，应用用户组倍率 |
| GET | `/api/admin/procurement` | 管理员 |
| POST | `/api/admin/procurement` | 管理员，按 `channel_id + model` 新增或覆盖报价 |

金额字段为整数 micros，`1` 个结算币种单位等于 `1,000,000` micros。采购 POST 字段：`channel_id`、`model`、`input_cost_micros`、`output_cost_micros`、`cache_read_cost_micros`、`cache_write_cost_micros`、`unit_cost_micros`、`monthly_budget_micros`、`supplier`、`notes`。可选金额可传 `null` 清空，每次 POST 覆盖完整报价。

新增迁移 `0008_channel_procurement.sql` 随后端启动自动运行。按常规流程备份数据库，更新前后端并重启后端即可。删除关联渠道售价时，相应采购报价通过外键级联删除。

## 验证

前端运行 `pnpm lint`、`pnpm build`、`pnpm test`。后端运行 `cargo test --workspace`。额外 PostgreSQL 集成测试：

```sh
DATABASE_URL=postgres://YOUR_USER@localhost/postgres cargo test -p zhiqiaoapi catalog_publication -- --ignored
```

该测试使用 SQLx 自动创建的隔离测试数据库，检查迁移、渠道发布过滤、用户组价格缩放及公开响应的数据边界。浏览器检查可使用网络拦截测试数据；这些数据不会写入生产目录。
