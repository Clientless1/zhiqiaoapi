# 智桥平台更新 · 2026-11-11

- 客户端：CC Switch 官方导入链接与手动配置；Codex 使用供应商专属 Bearer Key 和 Responses；Claude 的默认及推理模型保持在 Key 权限内。
- 调试台：根据输入 Key 获取模型，支持 Responses、Chat Completions、Anthropic Messages 和 JSON 接口调试。
- 优惠券：后台可直接发放给指定邮箱或全部有效用户，自动发送站内通知；公开券可以在优惠券页面领取。并发领取受总量、过期时间和每人领取限制保护。
- 邮件：智桥品牌、内嵌 Logo、纯文本备选正文及发送超时。收件箱头像仍由发信邮箱服务商管理。
- 认证：密码与邮箱验证码独立登录；GitHub/Google OAuth 使用 PKCE、浏览器绑定及一次性登录票据；已有账户可明确绑定第三方账号。
- 运维：OAuth 请求支持专用出站代理，模型流量沿用原有客户端。凭据加密保存在数据库中，订阅与代理节点配置留在服务器受限目录。

## 升级

先备份数据库、配置加密密钥和资源卷。后端会应用 `0018_auth_methods`、`0019_coupon_distribution`、`0020_oauth_account_linking`。生产部署始终沿用原有 external 数据卷。

当前京东云部署的 Compose 引用了专用 `zhiqiao-oauth-egress` 内部网络，详情见 [OAuth 代理运维](../../deploy/ops/oauth-egress.md)。其他部署可按实际网络移除该附件；不配置 `OAUTH_PROXY_URL` 时，OAuth 直接连接供应商。

客户端步骤见 [CC Switch 与手动配置](../client-setup.zh.md)。OAuth 控制台需设置站点回调地址：

```text
https://zhiqiaoapi.fun/oauth/github/callback
https://zhiqiaoapi.fun/oauth/google/callback
```

Google 应用如果仍处于测试状态，需在 Google Cloud 配置测试用户或发布为正式应用后，其他账号才可授权。
